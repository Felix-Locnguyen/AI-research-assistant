# EPIC 05 — Memory Management (T31–T37)

## Goal

Fill the empty `app/memory/` package and finish EPIC 05 so the assistant reliably remembers, updates, retrieves, and cleans up user memories across sessions. Decisions already made: **SQL-based retrieval** (no vectors/embeddings), **extraction = existing tools + post-turn extractor pass**, **full T31–T37 scope**.

## Current state

Working today: Telegram → `handle_message` (`app/conversation/handler.py`) → context (`context_builder.py`) → Gemini tool loop (`tools.py` with `save_user_preference` / `save_memory`) → `MemoryRepository`. Partial coverage: T31 = 20-msg history window; T32 = tool-calling only; T33 = strip/500-char/dup check in `MemoryRepository.add`; T36 = `cleanup_expired` at startup only; T37 = markdown appended in `load_system_prompt`. Missing: T34 (edit/delete), real T35 (retrieval is just "20 most recent"), and the `app/memory/manager.py`, `extractor.py`, `retriever.py` modules (all 0 bytes).

## Architecture

- `app/memory/manager.py` — facade + T33/T34/T37:
  - `validate_content(content: str) -> str` — raises `ValueError` (strip, max 500, min 10 chars, reject letter-less noise)
  - `build_context_markdown(preferences: dict[str, str], memories: list[Memory]) -> str`
  - `class MemoryManager(session)` — `save(user_id, content, expires_at=None)`, `update(user_id, memory_id, content, expires_at=None)`, `delete(user_id, memory_id) -> bool`, `list(user_id, limit=20)`
- `app/memory/retriever.py` — T35: `async def retrieve(session, user_id, query, limit=20) -> list[Memory]` — SQL pool (non-expired, `ORDER BY id DESC LIMIT 100`) then Python rank: lowercase tokens (drop len<3 + ~15 Vietnamese stopwords), score = token-in-content hits, sort `(hits desc, id desc)`, return top N. Zero-hit rows fill the tail so recency fallback still works.
- `app/memory/extractor.py` — T32: `async def extract(user_id, user_text, assistant_text) -> None` — own `SessionLocal`, calls Gemini with `prompts/memory-extractor.md`, writes via `MemoryManager.save`. Output = JSON via `response_schema` (list of `{content, expires_in_days?}`); empty list → no writes. Skip when text < 15 chars or starts with `/`.
- T31: no new module — the 20-msg window in `ConversationRepository.recent_messages` is the short-term state; tag it in a comment.

## Key constraints

- Naive UTC everywhere: `datetime.now(UTC).replace(tzinfo=None)` (matches `func.now()`), as `repository.py` does
- No new dependencies; no `__init__.py` (namespace packages)
- Both tool and extractor paths funnel through `MemoryManager.save` → single validation point; exact-dup skip in `add` protects against double-writes
- Tool descriptions stay terse (5 tools vs `MAX_TOOL_ROUNDS=3`; raise to 4 only if truncation observed)
- Comments in Vietnamese, matching existing style
