# EPIC 11 — Deployment & Operations (T65–T69)

## Goal

Máy khác: `cp .env.example .env` → điền secrets → `docker compose up -d --build` → chạy ổn định. Secrets an toàn, health quan sát được, docs vận hành, cảnh báo tùy chọn. (Queue trong T65 = `asyncio.Queue` in-process sẵn có — KHÔNG thêm redis/celery.)

## Key decisions (đã chốt với user)

- **T66:** `database_url` default `""` + fail-fast `RuntimeError("Thiếu DATABASE_URL ...")` trong `connection.py` (cùng pattern `llm.py` GEMINI_API_KEY). Tests an toàn vì conftest luôn set `DATABASE_URL` trước khi import app.
- **T69:** alert generic — `ALERT_WEBHOOK_URL` (rỗng = tắt), POST `{"text": ...}` qua stdlib `urllib` trong `asyncio.to_thread`, fire-on: lỗi 500 (global handler) + queue dead-letter. Không dependency mới.
- Compose `environment:` **thắng** `env_file:` → fix blocker `DATABASE_URL=localhost` trong container mà không sửa `.env` của user.
- Đổi shape `/health`: `200 {status, db, queue:{pending,dead_letters}, errors}` / `503 degraded` → test `test_health_ok` cũ phải cập nhật (intentional).

### 3. T69 — Monitoring & Alerts

**NEW `app/core/alert.py`** (full):
```python
"""Gửi cảnh báo vận hành tới ALERT_WEBHOOK_URL (T69) — fire-and-forget, không chặn request."""
import asyncio, json, logging, urllib.request
from app.core.config import settings
logger = logging.getLogger(__name__)
ALERT_TIMEOUT_SECONDS = 5

async def send_alert(message: str) -> None:
    """POST JSON {"text": message} nếu đã cấu hình; lỗi → nuốt + log warning."""
    if not settings.alert_webhook_url:
        return
    def _post() -> None:
        req = urllib.request.Request(settings.alert_webhook_url,
            data=json.dumps({"text": message}, ensure_ascii=False).encode("utf-8"),
            headers={"Content-Type": "application/json"}, method="POST")
        try:
            urllib.request.urlopen(req, timeout=ALERT_TIMEOUT_SECONDS)
        except Exception:
            logger.warning("Gửi alert thất bại")
    try:
        await asyncio.to_thread(_post)
    except Exception:
        logger.warning("Gửi alert thất bại")
```

## Edge cases

| Tình huống | Xử lý |
|---|---|
| `.env` có DATABASE_URL localhost khi chạy compose | `environment:` override → app nối host `db` |
| POSTGRES_PASSWORD chưa set | cả 2 service cùng default `postgres` qua `${…:-postgres}` — nhất quán |
| `.env` thiếu khi `compose up` | compose báo lỗi `env_file` → README `cp .env.example .env` |
| App khởi động trước DB | `depends_on: service_healthy`; restart nếu `init_db` crash |
| DB chết sau đó | /health → 503 → container unhealthy; restart KHÔNG tự kích hoạt trên unhealthy-only (đúng — tránh restart loop) |
| Tests không có PG | `@db` skip; degraded/middleware/connection/alert vẫn chạy; conftest luôn set DATABASE_URL trước import |
| Alert endpoint chết | urlopen exception → warning only — request không bao giờ fail |
| Middleware + unhandled 500 | exception raise qua middleware → handler tăng counter + alert; middleware log `-> 500` rồi re-raise |
| `_error_count` leak giữa test | reset trong autouse fixture test_api |
| ZoneInfo trong container | tzdata cài + probe trong verification; TZ chỉ ảnh hưởng log timestamp (dữ liệu vẫn naive-UTC) |
