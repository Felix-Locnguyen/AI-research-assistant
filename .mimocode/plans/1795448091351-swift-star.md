# EPIC 10 — Testing & CI (T61–T64)

## Goal

Green test suite; code changes do not break existing features. T61 unit tests per-module (repository, handler, memory...), T62 API tests với TestClient, T63 channel mock integration, T64 GitHub Actions CI.

## Key decisions (đã chốt với user)

- **DB tests = real Postgres + graceful skip:** test DB `nexus_ai_test` (auto-create nếu thiếu), tests gắn marker `db` skip tự động khi PG khôngreachable; CI cung cấp postgres:16 service. TRUNCATE 8 bảng giữa mỗi test. **KHÔNG BAO GIỜ** đụng DB dev `nexus_ai`.
- **CI: GitHub Actions, Python 3.12** (Docker parity), `pip install -r requirements.txt pytest` (không requirements-dev.txt).
- **Step 0 — restore `LLM_GATE` vào `llm.py`** (user xác nhận mất lạc ý trong commit `a709840`, suite đang 40 pass + 1 fail). Đây là thay đổi production DUY NHẤT của epic.
- Không dependency mới (pytest-asyncio/respx/aiosqlite cấm); `httpx.MockTransport` có sẵn — dùng được. Test name tiếng Anh snake_case; tiếng Việt chỉ trong string/comment.

## Critical discoveries (đã verify — tin cậy)

1. **Baseline: 40 pass + 1 fail** — `test_llm_generate_acquires_gate` fail vì `llm.py` thiếu `LLM_GATE` (grep xác nhận; AGENT.md L20/L37 + commit message vẫn ghi có) → Step 0.
2. **PG local password là `123456`** (từ `.env`), KHÔNG phải `postgres` (CI mới dùng postgres/postgres) → conftest **derive credentials** từ env/`.env`, chỉ swap tên DB → `nexus_ai_test`.
3. **`TestClient(app)` KHÔNG qua context manager → không chạy lifespan** (starlette chỉ chạy lifespan trong `__enter__`) → test API không cần PG, không spawn worker.
4. **500-handler test cần `TestClient(app, raise_server_exceptions=False)`** — ServerErrorMiddleware re-raise sau khi gọi custom handler.
5. pydantic-settings: **env var > `.env`** → set `os.environ["DATABASE_URL"]` trước lần import app đầu tiên là đủ (conftest load trước mọi test module — KHÔNG cần lazy-engine refactor).
6. Patch HTTP outbound: `zalo.httpx is httpx` → `monkeypatch.setattr(httpx, "AsyncClient", factory)` với factory trả **client thật** + `transport=MockTransport` (hỗ trợ `async with`native). Không bao giờ MagicMock làm client.
7. `app/api/*` và `conversation/router.py` là file rỗng — không test, không buildout.

## Edge cases (bắt buộc tuân thủ)

1. Engine-bind order: env set ở module-top conftest TRƯỚC import app — pytest guarantee conftest load trước; KHÔNG refactor production.
2. Test DB safety: LUÔN luôn force tên DB → `nexus_ai_test`; assert sau import.
3. PG local (`123456`) ≠ CI (`postgres`) → derive credentials, không hardcode.
4. Không bao giờ `with TestClient(app)` (sẽ chạy init_db + spawn 3 task nền + treo).
5. Queue state pollution: mọi file enqueue có autouse `_clean_queue`.
6. httpx patch: factory trả client thật với `transport=` — không MagicMock, không drop `kwargs`.
7. Monkeypatch bound name trong module under test (`job_queue.handle_message`, `handler.llm.generate`, `extractor.llm.generate`...).
8. Handler db-test: monkeypatch `handler.extractor.spawn` no-op (tránh task rò rỉ).
9. Không network: Gemini/DDGS/live channel hosts không bao giờ được gọi.
10. Assert message tiếng Việt khớp fragment production (`match="rỗng"`...).
