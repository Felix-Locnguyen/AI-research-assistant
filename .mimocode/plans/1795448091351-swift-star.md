# EPIC 08 — Zalo & Messenger (T54–T57)

## Goal

Hoàn thiện kênh Zalo OA + Facebook Messenger và chuẩn hóa interface outbound trong `channels/base.py` để cùng một luồng xử lý chạy trên cả 3 kênh (webhook → normalize → `handle_message` → gửi trả lời), bao gồm cả lời nhắc qua `notifier`. Kèm xác thực chữ ký webhook cho cả 3 kênh (đóng lỗ hổng đã ghi ở AGENT.md).

## Key decisions (đã chốt với user)

- **T54 outbound:** dispatcher module-level trong `base.py`: `async def send_text(channel, user_id, text, proactive=False)` — lazy-import các module kênh **bên trong hàm** để tránh circular import (`telegram.py → conversation.handler → channels.base`). Reply trong mỗi kênh tự gọi `send_text` của chính nó (giữ nguyên pattern hiện tại, `scripts/telegram_poll.py` không đổi); dispatcher là call-site duy nhất cho notifier.
- **Zalo auth:** chỉ `ZALO_OA_ACCESS_TOKEN` trong env — token hết hạn ~1h, cập nhật thủ công (ghi chú trong code + `.env.example`). KHÔNG làm refresh-token flow.
- **Webhook security cho cả 3:** Telegram `X-Telegram-Bot-Api-Secret-Token` (so sánh nguyên văn), Zalo `X-ZEvent-Signature` (HMAC-SHA256 raw body, `sha256=` + hex), Messenger `X-Hub-Signature-256` (HMAC-SHA256). Secret rỗng = dev mode, bỏ qua xác thực. Sai chữ ký → **403** (không xử lý); lỗi xử lý/gửi vẫn trả 200 để platform không retry lặp.
- **Messenger proactive (lời nhắc):** `proactive=True` → `messaging_type=MESSAGE_TAG` + `settings.messenger_tag` (mặc định `ACCOUNT_UPDATE`) vì ngoài cửa sổ 24h `RESPONSE` bị từ chối; reply thường dùng `RESPONSE`. Zalo/Telegram bỏ qua cờ này.
- **T57 tests:** greenfield `tests/` với pytest 9.2 sẵn có, **không thêm dependency mới** — `asyncio.run()` trong test sync, `unittest.mock`, gọi thẳng hàm endpoint với `FakeRequest` (không dùng `TestClient` vì lifespan sẽ gọi `init_db()` cần DB thật).

   - `ZALO_API = "https://openapi.zalo.me/v3.0/oa"`
   - `async def send_text(user_id, text)` — POST `f"{ZALO_API}/message/cs"`, header `access_token`, body `{"recipient": {"user_id": ...}, "message": {"text": ...}}`, `raise_for_status`, timeout=10.
   - `async def process_webhook(payload, session)` — chỉ nhận `event_name == "user_send_text"`; `text = (payload.get("message") or {}).get("text")`; `user_id = str(sender.get("id", ""))` (guard rỗng); `username = sender.get("display_name")`; build `IncomingMessage(channel="zalo", ...)` → `handle_message` → `send_text(user_id, reply)` trong `try/except httpx.HTTPError: logger.exception` (comment: ngoài cửa sổ 48h CS sẽ rơi vào đây, vẫn trả 200).
   - `@router.post("/webhooks/zalo")` — đọc `raw = await request.body()`, `verify_hmac_signature(raw, headers.get("X-ZEvent-Signature"), settings.zalo_webhook_secret)` → 403 nếu sai; `json.loads(raw)` trong `try/except ValueError` → log warning + `{"ok": False}` (200); rồi `process_webhook`.
   - Docstring/comment ghi rõ token Zalo hết hạn ~1h, cập nhật thủ công.

6. **`app/channels/messenger.py`** (viết mới, T56):
   - `GRAPH_API = "https://graph.facebook.com/v19.0"`
   - `async def send_text(user_id, text, proactive=False)` — body `{"recipient": {"id": ...}, "messaging_type": "MESSAGE_TAG" if proactive else "RESPONSE", "message": {"text": ...}}`; nếu `proactive` thêm `"tag": settings.messenger_tag` (top-level). POST `f"{GRAPH_API}/me/messages"` với `params={"access_token": settings.messenger_page_access_token}`, `raise_for_status`.
   - `async def process_webhook(payload, session)` — duyệt `entry[].messaging[]`; bỏ qua `message.is_echo` và tin không có `text`; `user_id = str(sender.id)` guard rỗng; `username=None`; reply qua `send_text(user_id, reply)` (proactive mặc định False) với swallow-and-log.
   - `@router.get("/webhooks/messenger")` — handshake với **Query alias** (FastAPI không tự map dấu chấm):
     ```python
     hub_mode: str | None = Query(None, alias="hub.mode"),
     hub_verify_token: str | None = Query(None, alias="hub.verify_token"),
     hub_challenge: str | None = Query(None, alias="hub.challenge"),
     ```
     `hub.mode == "subscribe"` + verify token đã cấu hình + `hmac.compare_digest` match → `Response(content=hub_challenge, media_type="text/plain")`; sai → 403 (strict, không dev-skip).
   - `@router.post("/webhooks/messenger")` — raw body + `verify_hmac_signature(..., headers.get("X-Hub-Signature-256"), settings.messenger_app_secret)` → 403; JSON hỏng → `{"ok": False}` (200); rồi `process_webhook`.

## Edge cases đáng nhớ

- Đọc raw body **một lần** (`await request.body()`) rồi `json.loads` — không trộn `request.json()` với kiểm tra chữ ký (chữ ký phải khớp đúng bytes).
- `sender.id`/PSID có thể là số trong JSON → luôn `str(...)` trước khi vào `IncomingMessage`.
- Messenger echo (`is_echo`) = tin của chính page → bỏ qua.
- Zalo 48h CS window / Messenger 24h window: thất bại ngoài cửa sổ → swallow-and-log, `notify` trả False, scheduler tick sau thử lại (mất lời nhắc tệ hơn retry mỗi phút — giống convention EPIC 07).
- `handle_message`/DB lỗi → không bắt riêng, global handler trả 500 (giống telegram hiện tại).
